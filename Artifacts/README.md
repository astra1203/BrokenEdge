# 阶段报告与验收归档

这里保存按功能和场景组织的实施报告、截图、日志、数据快照及验收证据。

| 目录 | 内容 |
|---|---|
| [Extraction](Extraction/) | 搜打撤功能、玩法验证、恢复记录与实施方案 |
| [SpaceCenter](SpaceCenter/) | 航天基地转换、场景恢复与验证记录 |
| [Stinger](Stinger/) | 角色、动画、第一人称表现与验证记录 |

2026-11-09，这三个目录从 `Docs` 整体迁入，内部结构保留。项目总体说明、需求和通用专题文档仍在 [Docs](../Docs/)。

现用脚本的读写路径、文档导航、Git 属性及忽略规则已随迁移更新。历史证据目录中的日志、清单和源码快照保留原始内容，其中出现的旧路径表示采集时的位置；查找对应归档时，将项目内的 `Docs/Extraction`、`Docs/SpaceCenter`、`Docs/Stinger` 前缀替换为 `Artifacts` 下的同名目录。

证据目录里的源码副本不是当前实现。修改功能应使用项目根目录的 `Source`、`Scripts`、`Config` 和 `Content`。
