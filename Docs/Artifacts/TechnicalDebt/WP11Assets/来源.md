# 输入资产来源

18 个新资产由 Scripts/Extraction/prepare_input_actions.py 在 UE 5.8.4 中生成；16 个 IA、2 个 IMC。脚本检测到目标已存在时拒绝覆盖。随后在独立 UE 进程重新加载审计，共读到 26 个 IA、4 个 IMC。未改动原 CharacterDefault/Stinger IMC，也未修改现有动画或蓝图。C++ 绑定迁移另行提交。

IA_Heal 组合 Hold(0.35 s) 与 Tap(0.35 s)，分别处理长按自用和轻点切激素枪；取消不解释成轻点。低抛复用可重映射的 IA_HoldBreath 修饰动作状态；不采用原方案的独立 Chorded 低抛动作，避免低抛修饰键切换导致主投雷动作完成/取消而误投。对应按键与资产 SHA 见报告；后续运行时验证单列。
