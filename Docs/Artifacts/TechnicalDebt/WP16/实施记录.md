# WP-16 任务稳定 ID 实施记录

基线 95d769eca，UE 5.8.4 / CL 58902052。接口、固定映射和兼容边界见 [任务稳定 ID 与迁移](../../../任务稳定ID与迁移.md)。

任务定义、状态、请求、回执、HUD/结算提示和任务页已统一稳定 ID。定义支持目标类型、前置 ID 列表和最低等级，校验重复/未知 ID 与依赖环；新增目标不重置旧进度。任务页支持每页三行滚动。测试驱动 JSON 和网络场景脚本改为 quest_id 字符串，实际网络场景尚未跑。

v9 迁移保留原有物品、余额、经验、领取状态和文件资格，Revision 加一。真实 v8 fixture 的字段仅有 accepted / claimed / progress / delivered / eligibleFiles，不含 QuestId。迁移在定义重排时仍按固定旧索引映射，备份逐字节一致；备份失败、提交失败、重启重试和旧回执拒绝重复奖励均通过。

最终构建 43.59 s。Progression 7、Persistence 6、Equipment 4、Inventory 7，共 24 项测试通过；均使用独立 Saved 存储。Python 入口语法及 git diff --check 通过。
