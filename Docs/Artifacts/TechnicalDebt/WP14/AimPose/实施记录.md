# 第三人称瞄准测量修正

2026-11-14，基线 `2463bd89f`，UE 5.8.4 / CL 58902052。

此前 ThirdPersonAimPose 用“武器网格原点 → MuzzleFlash 位置”构造枪管轴线。网格原点接近握持位置、偏离枪管，这条连线会人为抬高俯仰角，向视点反向延长后把眼线距离高估为 27.0 cm。

本轮在同一真实 PIE 帧同时记录两种测量：旧连线 27.0 cm / 9.0°，枪口插槽朝向对应的轴线距视点 17.78 cm。记录包含视点、网格原点、枪口世界位置/朝向和手臂骨骼位置；临时关闭伸手修正后结果反而变差，未把它作为生产修复。诊断补丁压缩在 Probe.patch.gz，可对基线还原；失败运行与事件保留。

最终测试改用 MuzzleFlash 的世界位置和 X 轴朝向，并明确要求插槽存在。原 20 cm 眼线、20° 朝向、开镜至少靠近 5 cm、松开后回到腰射姿态的阈值均保留。删除临时关闭 IK 的步骤，保留只读的枪口几何日志。角色、武器、动画资产和生产逻辑未修改。

最终构建通过（10.95 s）；完整 WeaponPIE 4 项通过：InputAndAssembly、RifleLocomotionStability、SprintTransitions、ThirdPersonAimPose。最终腰射 27.0 cm / 39.7°，瞄准 17.8 cm / 2.0°。本项结论是修正测量误报，不代表所有武器、角色、远端或俯仰角的完整视觉验收。

当前会话缺少 Rider 调试器接口，按 debugging-code 的工具可用性规则采用真实 PIE 运行值作为证据。新增 aim-pie 独立入口便于定位同一用例。原始日志位于同名 Saved/Extraction 目录。
