# WP-17 HUD 采样与刷新优化

基线 `53a583c6a`，UE 5.8.4 / CL 58902052。测量环境与刷新契约见 [HUD 刷新与采样](../../../HUD刷新与采样.md)。先插入观测点取得基线，再加入注册表/文本去重，最后减少离散状态的重复格式化。

| 同场景 60 秒采样 | Refresh 次数 | 平均 ms | P95 ms | 最大 ms | SetText 尝试 / 实写 |
| --- | --- | --- | --- | --- | --- |
| 基线 | 3600 | 0.118380 | 0.136402 | 0.294000 | 43200 / 43200 |
| 撤离注册表 + 文本去重 | 3600 | 0.111506 | 0.126801 | 0.243202 | 43200 / 480 |
| 加入状态缓存，最终通过轮次 | 3599 | 0.094658 | 0.107702 | 1.713000 | 25193 / 480 |

最终平均值下降约 20.0%，P95 下降约 21.0%，实际 SetText 减少约 98.9%。这是一次受控场景对照，未做统计显著性检验；最大耗时存在更高尖峰，不能据此宣称尾部卡顿已解决。该数值仅覆盖 Refresh 的 CPU 区间，不代表总帧耗时、Slate/GPU 或大地图表现。

三轮成功采样分别保存于 `td_wp17_baseline_20261113_01`、`td_wp17_after_20261113_01`、`td_wp17_hud-profile_20261113_04`。最终源码指纹为 `VerifiedSources.json`，插桩基线指纹为第一轮目录的 `BaselineSources.json`。原始 `.utrace` 留在同名 Saved 目录，仓库归档 Insights 导出的 CPU 事件 CSV 以及 trace 大小、SHA-256 和命令。

最终构建通过（11.71 s）。HUD 1、库存 7、撤离反馈 3、生命 1，共 12 项不同测试通过。HUD 用例在计时区间之后覆盖动态撤离点增删、死亡/恢复显示、生命及护甲提交、Pawn 释放/重占、Widget 重挂、任务版本变化。

保留了中间失败证据：提取函数的局部变量遮蔽、测试 TObjectPtr 取裸指针遗漏已修复；第三轮测试误把生命增量当绝对值，并假设靶场初始有头盔，现按真实接口准备夹具。该失败轮次的性能报告仅作过程记录，不作为最终通过证据。Insights 初次导出受 UE 原生命令解析和工作目录影响未输出目标 CSV，已改为无 shell 的显式值引号与绝对输出路径，保留失败元数据。

未完成：远端客户端重连、完整观战切换、真实流送子关卡和 SpaceCenter 地图采样。当前已验证本地 Actor/Widget/Pawn 生命周期，但不把它等同于网络验收。
