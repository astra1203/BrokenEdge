# WP-12 第二阶段：恢复预算和网络救援

引擎 UE 5.8.4 / CL 58902052；代码基线 `1070e784b` 加本批改动。所有运行使用独立报告目录和 D 盘缓存；未修改用户的 EngineAssociation。

## 发现和修复

- 旧持续回血/回盾在最后一帧按完整帧间隔结算，10 HP / 1 s 用两帧 0.75 s 会恢复 15 HP，20 Shield 会恢复 30。现在按剩余预算钳制。
- 非法恢复量、时长或帧间隔拒绝；速率溢出或下溢也拒绝，保留现有合法恢复。
- 双客户端真实网络测试发现初次救援失效：服务器接管角色时先执行两次序号取消，LastSequence=2，客户端第一条 Begin 的 Sequence=1 被丢弃。服务器自身取消改为直接清理动作；客户端的递增序号和旧请求拒绝不变。

## 覆盖边界

`vitals-net-pie_05` 使用训练场、同进程专服和两个真正网络客户端，各 NetDriver 设置 150 ms 延迟、5% 丢包。覆盖友伤、护甲破损/所有者库存复制、观察者无私有库存、止血、医疗包、HP/Shield 同次写入、定时 Buff、倒地池、首次客户端救援、取消锁释放、旧请求重放及正常五秒救援。伤害和初始位置由服务器夹具布置，救援走真实客户端可靠 RPC，未加速完成计时。
