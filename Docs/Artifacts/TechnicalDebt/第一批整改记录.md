## 方案修正

首次重生测试失败揭示：UE 5.8 的 `FindPlayerStart_Implementation` 在找不到出生点时返回 WorldSettings，`Super::RestartPlayer` 会继续在其位置生成 Pawn。因此不能同时照搬方案中的无条件 Super 回退和“不生成在世界原点”要求。实现优先保证后者，保留引擎选择逻辑，仅拒绝 WorldSettings 回退。

事务层不能对所有 Edit 一律断言 GUID 集合和总数量完全不变：合法拆堆/合堆会改变 GUID 集合，医疗/射击会减少数量。当前将数量、GUID 和来源批次守恒放在真实转移/回滚测试中；若后续要加入统一调试断言，需要先明确操作类型与合法增减规则，不能误拒消费或初始化。
