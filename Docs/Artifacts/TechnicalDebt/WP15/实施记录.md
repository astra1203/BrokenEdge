# WP-15 资源登记与生成保护（第一阶段）

基线 410580036，UE 5.8.4 / CL 58902052。接口和操作见 [物品注册表](../../../物品注册表.md) 与 [生成资产清单](../../../生成资产清单.md)。

- 新注册表包含 367 个稳定物品 ID，完整覆盖旧白名单及收集品 inl；新进程加载全部通过。保存身份不依赖资产路径，错误映射拒绝加载，旧白名单回退明确告警。Ids 按名称排序，因此同一历史随机种子的掉落抽样可能变化，既存物品不迁移。
- 源资源和 Cook 规则检查读取带资产指纹的注册表导出，拒绝过期清单；381 个运行时包检查通过。补齐地图配置注册表输入和 Enhanced Input 目录 AlwaysCook。提供可选松散 Cook 输出阶段，包内 Client/Server 阶段明确为未执行。
- 两个原生 Widget 生成器在任何树修改前检查整个目标集合；未知基线或手改时默认中止并报告字段差异。只有显式 --force 可覆盖。保存后写旁路快照，统一任务随后启动独立进程重载编译验证。
- 当前生产 Widget 没有可信生成历史基线，未通过强制重建来覆盖现有内容，也未自动认领现有树为历史生成结果。测试临时建立旁路文件、修改内存文字，验证默认拒绝并完整恢复；工作区无残留测试基线。

最终构建通过，30.85 s。25 项不同 Unreal 自动化测试通过：注册表 1、库存 7、持久化 6、装备 4、生成保护 1、掉落布局 1、进度 5。11 个界面/容器蓝图在独立编辑器中加载编译通过，全部 BS_UP_TO_DATE；8 项纯 Python 检查通过。

真实失败及修正：首次生成保护构建遇到 UE 5.8 JSON 键使用共享字符串的问题，显式转换为 FString 后构建通过。掉落布局旧测试只接受骨骼模型，拒绝了运行时支持的静态模型；检查调整为任一合法外观且配方存在，并移到每个候选一次的预检后，1000 随机种子回归通过。初次失败报告过大，仓库保留按事件去重的统计、原报告路径与 SHA-256，完整原件在 Saved 中；未修改掉落资产来迎合测试。

未完成：实际 Cook、包内双端进图开背包、生产界面强制生成及新基线跨进程一致性、美术可手改子 Widget 的拆分。现有树结构/文字/布局受到保护，Blueprint Graph 和主界面 CDO 类绑定不在快照范围。不能将本阶段视为 WP-15 全部验收完成。WP-14 的已归档 Events 去除了大量启动缓存噪声，原自动化结果与失败结论保留。
