# Enhanced Input 迁移

资产提交 4348ef91a；本批绑定控制器所有原始 BindKey，移除 Character 的 HoldBreath/InteractDoor 旧映射及 INI 对应行。IA_Interact 接管 E 的开始/完成/取消；G 完成投雷、取消收起；IA_Heal 的 Hold/Tap 决定长按与轻点；菜单/背包/失焦统一取消。背包旋转使用高优先级 IMC_ExtractionUI，移除 R 轮询；关闭界面及 EndPlay 移除上下文。旧 G 丢弃映射在撤离上下文优先级下被投雷映射覆盖，旧模式原映射仍保留。

实际验证：Runtime/StingerTools 编译通过；单玩家真实 PIE 将投雷/交互/治疗重映射到 F6/F7/F8、修饰动作改为 K、背包旋转改为 Y，验证投雷实际消耗一次、救援松开取消、修饰键单独松开不投雷、失焦不触发治疗轻点、轻点切枪/长按自用、菜单停止连射以及真实拖拽操作只旋转一次。通过记录 td_wp11_remap_20261113_03。

回归暴露并修复训练场自用治疗被队伍校验拒绝的问题：失败观测 CanStart=1、Squad=0、Life=Alive、Falling=0、Action=None。ValidTarget 现在对本人只校验生命状态，对其他角色继续校验友方；修复后同场景 Action=Heal。会话没有 Rider 调试器工具，采用自动化状态记录定位，未声称执行断点调试。

未覆盖：完整双客户端/打包运行、操作系统真实失焦（用例调用同一失焦处理入口）、Slate 鼠标捕获的完整拖放链。之前 WeaponPIE 第三人称瞄准姿态 26.9 cm 超过 20 cm 的失败仍待处理，未放宽阈值。
