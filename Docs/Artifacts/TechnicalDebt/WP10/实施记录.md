# 有界历史保留

用户确认：每档案最近 1024 条经济回执，全库最近 128 个已关闭对局；开放对局和被来源引用的记录保留。候选状态先完整校验，再修剪、序列化、CRC、Flush；只有写入成功才替换内存状态。

状态版本升到 8。加载旧档先逐字节保留 .v<版本>.bak，再迁移。新增 ClosedSequence 记录关闭事务顺序；旧档没有关闭时间，迁移时同序记录按原数组顺序取最后 128 个，此后按关闭序号排序。仍支持 v1 帧及 v7/v8 SegmentStart。低版本迁移期间不提前滚动。

引用扫描包括仓库、出战配置、溢出、最近结果中的物品/弹匣/附件来源，以及开放对局的入局原件。闭局的 Exported 或 Original 来源仍被引用时整条保留，因此 128 是无引用历史窗口，不是全部闭局的硬上限。

窗口内相同操作及签名命中原回执。窗口外原始请求保留旧 Revision，被现有服务器校验拒绝；不提供无限期 Operation UUID 去重保证。删除的 Raid ID 在 Settle 查找失败，客户端不能指定 BeginRaid 的新 ID，因此不会重新发放。

测试覆盖 1030 条回执裁到 1024、132 个闭局裁到 128 加被引用例外、开放记录保留、旧请求拒绝、窗口内幂等、被删对局重复结算拒绝、v7 精确备份和迁移，以及重新加载。经济/容量和输入取消回归也通过，完整运行记录见本目录。

容量三档原始输入与 WP-08 一致。最大档（100 档案，每档案 2000 回执，2000 闭局）快照 9,155,849 字节，Commit 210.19 ms，Load 223.01 ms；之前分别为 18,352,489 字节、432.59 ms、448.89 ms。均为本机单次测量，进程峰值约 4.72 GB；不据此宣称生产延迟保证，也未优化同步磁盘写入。
