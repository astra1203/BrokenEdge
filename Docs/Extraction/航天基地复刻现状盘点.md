# 航天基地搜打撤复刻现状盘点

> 盘点日期：2026-10-27。分支 `ue5.8-20260930`，基线提交 `0632243b`。范围只含烽火地带（搜打撤）模式的航天基地地图。
>
> 依据：当前源码、[官方功能差距审计](官方功能差距审计.md)（2026-10-24）之后的提交记录，以及由解包资产生成的点位证据（出生、撤离、保险柜）。本次没有运行游戏，也没有直接使用逆向工具或客户端目录，所以以下状态均来自源码和已有证据，不是实机验收。
>
> 状态含义：**已复刻**表示有源码与证据支撑；**部分复刻**表示机制存在但内容、规则或验证不完整；**未复刻**表示在已检查的模块和入口中找不到对应能力。

## 1. 总体结论

搜打撤完整流程已经可以联机跑通。地图、出生点、撤离点和保险柜点位主要来自解包数据。与官方相比，主要差距集中在三方面：

- 全图还没有走通，还原区域之间的连通性未经验证；
- 撤离规则、掉落内容和物品数量远少于官方；
- 安全箱、胸挂与背包栏位、投掷物、其他干员、Boss 等系统尚未建设。

## 3. 部分复刻

| 模块 | 已有部分 | 差距 |
| --- | --- | --- |
| 全图连通性 | 中控和发射区几何已并入正式地图 | 中控区真实行走测试 5 次全部失败（楼梯阻挡、路线卡住等）；东区返回路线卡在第 165 点，并入前已有同样问题；主区到发射区的原版连接方式未查清，按要求未自行补桥 |
| 出生／撤离覆盖 | 45 个点位与 3 个撤离点数据齐全 | 根据已还原区域范围推测，9 个出生组可能只有中控北、发射南能落地，3 个撤离点可能只有广场在范围内；需要运行 `--audit` 确认 |
| 广场撤离 308 | 位置已还原 | 官方为 4 个触发器随机开 2 个、900 秒开放、开后 120 秒关闭；开关逻辑未实现 |
| 德穆兰撤离 309 | 位置已还原 | 官方需上交 5 个指定物品或 1 个通行物，最多 3 人；付费条件未实现 |
| 撤离时间 | 支持开放、关闭与容量配置 | 默认不使用官方时间；可选开关按 1/3 折算进 600 秒一局，1/3 为项目自定比例 |
| 掉落内容 | 服务端一次选取、稳定 ID、4 个变体布局 | 官方掉落表和概率未取得；散落物资点按 20 m 网格自动生成，不是官方点位 |
| 物品种类 | 25 个物品定义 | 带图标的约 7 个；容器种类少；与官方物品库差距大 |
| 钥匙门 | 开门、次数消耗、档位战利品 | 无开门动画和音效；钥匙门与源地图房间的对应关系未恢复，部分钥匙房为项目自建 |
| 改枪深度 | 附件槽类型已定义 10 种 | 实际只有 3 个附件；无改装方案保存与套用；精校规则无证据来源 |
| 画面 | 基础色贴图已恢复 | 无原版多通道着色器和烘焙光照，地形边缘仍有截断 |

## 4. 未复刻

| 模块 | 说明 |
| --- | --- |
| 装备栏位 | 无安全箱，也无容量各异的胸挂和背包；当前背包为固定格子 |
| 投掷物 | 无破片手雷、闪光弹，只有烟雾弹 |
| 干员 | 除蜂医外的其他干员均未实现 |
| 敌人 | 无 Boss 或特殊敌人，官方敌人分布方式未还原 |
| 密码房 | 源码和脚本中均无航天基地密码房相关实现 |
| 武器内容 | 无第三把枪，无完整弹种与护甲系列；弹道无下坠，子弹不能穿墙 |
| 局外系统 | 无交易行、特勤处制造和官方经济；无互联网匹配；不能断线后回到同一局 |
| 声音 | 无听声辨位、室内外混响和分地表脚步声 |
| 性能与交付 | 6 人联机冷启动加载失败（客户端连接超时）；此前完整打包卡在 Zen 暂存阶段；全图性能未验收 |

## 5. 建议的下一步

1. **先让全图连通，再加内容。** 修好东区返回路线和中控区的行走阻挡，运行出生点与撤离点落地审计。否则 9 个出生组和 3 个撤离点里的大部分实际用不上。
2. **补齐两个撤离规则。** 广场随机开关和德穆兰付费撤离都已有现成的源数据，改动小、效果明显。
3. **补装备栏位与物品内容。** 安全箱、胸挂和背包，再加上掉落表和图标，对搜打撤体验影响最大。
4. **完善改枪与武器。** 先补 AK 的枪托、弹匣、枪管与方案保存，再适配第三把枪，然后加入破片手雷。
