# 大厅与 UI 对照

来源为本地解包版本，不代表当前线上版本。`SourceIcons.json` 记录归档路径和哈希；没有取得同版本完整官方页面截图，因此不使用“像素级还原”或还原度百分比。

| 页面 | 本轮交付 | 来源与具体差异 |
| --- | --- | --- |
| 大厅 | 独立本地三维角色、小队人数、主武器预览、资金、地图、配装、商店、任务、准备与取消 | 蜂医模型及空手展示循环来自已有源资产；持枪使用项目重定向步枪待机。棚景、灯光和页面布局为项目设计，并非官方大厅场景；小队成员暂共用蜂医外观，预览不包含全部附件或独立装备外观。 |
| 仓库／配装 | 保留真实网格、槽位、拖放和权威库存；补充源图标和品质条 | AK/SCAR 图标按源武器 ID 对应。弹药及工具／电子产品为注明的兼容映射。没有确认来源的物品继续使用文本；没有伪造全物品图集。 |
| 背包／搜索 | 相同图标、颜色与居中缩放；继续使用搜索进度、容量、数量、右键操作、旋转、拆分和拒绝消息 | 规则来自原有库存事务；不是重写成只可展示的假网格。未恢复官方全套搜索动画、音效和容器开盖。 |
| 改枪／详情 | 复用既有属性、兼容槽位和服务端应用请求；纳入相同页面缩放与鼠标换算 | 既有改枪布局保留；未获得完整官方改枪页面及全套 SCAR 独立附件。 |
| 商店／任务 | 大厅入口、原型任务和价格、键盘返回、统一画布 | 价格、奖励及任务链是项目规则，不冒充官方经济系统。 |
| 局内 HUD | 保留生命、护甲、弹药、方向、交互、行动与撤离提示 | 本轮继续使用现有项目 HUD；未恢复完整官方视觉层级、声音提示和全部反馈动画。 |
| 战术地图 | M 开关，Esc 关闭；本人、同队队友和撤离点共用世界投影；侧栏显示相对高度与撤离条件 | 从已恢复关卡的 53 个地面／平台包围盒生成轮廓。没有使用无法确认地图归属的图集；非精确官方楼层图，暂不支持缩放与分层筛选。 |
| 死亡观战／结算 | 继续使用原有观战权限与持久化结算；自动返回大厅后刷新仓库和展示对象 | 现有文字反馈保留，未制作官方逐页战报、收益动效和完整死亡回放。 |

验收脚本为 `Scripts/Extraction/lobby_ui_scenarios.py`。`Acceptance.json` 逐次记录分辨率、渲染客户端数、延迟／丢包参数、断言和截图。角色持枪截图用于检查展示，不能替代实战双手 IK 的运行断言。单人验证通过测试房间的最少人数配置，不改变默认双人开局规则。

本轮修复包括：UMG 容器打开后将键盘焦点交给内部 Slate；超宽屏绘制与鼠标点击使用同一缩放和偏移；开容器自动关闭地图；离开大厅销毁本地展示对象，返回后只创建一个；预览仅读取已提交主武器，不生成具有业务逻辑的武器 Actor。
