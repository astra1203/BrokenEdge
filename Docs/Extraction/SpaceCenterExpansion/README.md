## 本批操作

2026-10-23 后续调整：从大厅准备后进入航天基地，空副武器槽每局自动配备满弹匣 SCAR-H（20 发），并补给 60 发 7.62×51 mm 弹药；按 `2` 切换即可使用，不必先去商店购买。

副武器槽已有 SCAR-H 时保留现有武器和弹匣状态；已有其他枪时保留原枪，将赠送的 SCAR-H 放入出生旁的“开局补给”箱。背包先接收能放下的弹药，剩余部分进入该箱。补给使用正常掉落、拾取和撤离保存规则，每人每局初始化一次，加载重试不会重复发放。商店仍可额外购买。

验证记录：`Saved/Extraction/StartingScar01/Automation/index.json` 的 4 项扩展测试全部通过（含槽位占用、部分堆叠溢出、撤离写盘重载）；`Saved/Extraction/StartingScarNet01/Report.json` 的 26 项双客户端检查通过，使用真实开局发放而非库存夹具，验证按键切枪、射击、换弹、初始化重试与正常撤离保存。场景位置仍由测试夹具布置；满载补给箱位置未单独做视觉验收。

- `3`：选择常驻战术刀；左键轻击，右键重击。
- `1`：返回当前枪；`2`：交换当前枪和背枪。
- 刀不占两个枪械槽，不消耗子弹；攻击、射程、冷却与阻挡由服务器判定。
- 刀的伤害、射程、时序和手部偏移是临时参数；目前没有处决、刀皮肤或独立刀具仓库条目。
