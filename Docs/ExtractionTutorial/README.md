# 搜打撤源码教学页面

双击 `index.html` 即可打开。所有内容、脚本、样式和源码快照均在本目录，不需要联网、安装依赖或启动服务。请保留整个目录；源码文件链接和旧教程入口依赖当前仓库的相对结构。

## 阅读

- 首页进入八个章节；搜索支持中文功能、技术和 C++ 函数名，按 `/` 聚焦搜索，`Esc` 清空。
- 调用链支持切换路径、上一步、下一步、播放、暂停、重置及点击任意节点。RPC、复制、Tick 和异步回调单独标注；它是讲解顺序，不是一份运行时 trace。
- 代码块是提取时的真实函数全文，附路径、行号与文件 SHA-256。复制定位不可用时展开“手动复制与来源”，选择文本后按 Ctrl+C。
- 三个实验分别演示库存版本冲突、撤离条件与中断、存档提交边界与重复结算，均为浏览器模拟，不连接游戏或服务器。
- 主题、最后阅读章节和手动标记的已读记录保存在本地浏览器中。`file://` 下浏览器可能限制存储；不可用时自动退化为当前页面内使用。
- 深色模式和窄屏布局由本地 CSS 提供；“下一章”继续阅读。源码和旧教程链接由浏览器决定打开或下载行为。

## 文件职责

| 文件 | 用途 |
| --- | --- |
| `index.html` / `styles.css` | 入口与响应式样式 |
| `content.js` | 人工核对的章节说明、调用关系和源码引用 |
| `app.js` | 页面渲染、播放器、搜索、主题和阅读记录 |
| `simulations.js` | 三个确定性教学状态模型 |
| `sources.js` | 自动生成的离线函数快照与来源元数据 |
| `refresh-sources.cjs` | 从当前仓库提取函数，无第三方依赖 |
| `verify.cjs` | 来源一致性、内容完整性与模拟边界验证 |
| `verify-dom.cjs` | 可选的 JSDOM 交互测试，不是浏览器布局验收 |

## 源码变更后的维护

在仓库根目录运行：

```powershell
node Docs/ExtractionTutorial/refresh-sources.cjs
node Docs/ExtractionTutorial/verify.cjs
```

提取器验证每个函数和关联测试文件存在，保存当前提交、引用源码的未提交状态、文件哈希、起止行号及函数全文。找不到函数时立即失败，不生成占位内容。

**刷新快照不会自动纠正讲解。** 分支、RPC、数据字段或调用关系变化时，必须同时核对 `content.js`、实验假设与验证用例。不要把生成日期当作游戏功能已经实测的证明。

可选 DOM 验证需要从独立工具目录传入已安装的 `jsdom` 模块路径：

```powershell
node Docs/ExtractionTutorial/verify-dom.cjs "<工具目录>/node_modules/jsdom"
```

页面运行本身不需要 JSDOM 或 Node.js。

## 验证边界

当前交付已执行 JavaScript 语法检查、源码快照一致性检查、三个模拟的边界测试及 JSDOM 页面交互测试。DOM 测试覆盖本地文件入口、禁用存储与剪贴板时的降级、章节与调用链、搜索、主题和三个实验。

本环境的浏览器控制通道不可用，尚未进行真实浏览器截图、桌面/平板/手机尺寸的视觉验收及浏览器控制台检查。JSDOM 不计算真实布局，不能替代这些检查。未重新运行 UE 编译、PIE 或游戏网络测试。
