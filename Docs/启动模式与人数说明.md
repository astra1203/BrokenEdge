# BrokenEdge 打包版启动模式与人数说明

客户端通过启动参数选择要搜索、加入的模式；专用服务器决定实际游戏模式、房间容量和开局人数。无需修改 `TeamsGameMode.cpp`。

本文依据当前源码整理，已核对下列打包程序路径存在；本次未启动游戏验证，现有打包程序是否包含最新源码需以实际构建版本为准。

## 1. 打包程序位置

相对于 `C:\UnrealProjects\BrokenEdge\Packaged`：

| 用途 | 程序路径 |
|---|---|
| 专用服务器 | `Server\WindowsServer\BrokenEdgeServer.exe` |
| 客户端 | `Client\Windows\BrokenEdge.exe` |

## 2. 团队模式：最多 8 人，2 人开局

先打开一个 PowerShell 窗口，启动服务器：

```powershell
Set-Location 'C:\UnrealProjects\BrokenEdge\Packaged'
& '.\Server\WindowsServer\BrokenEdgeServer.exe' /Game/Maps/Lobby -MatchType=Teams -NumPublicConnections=8 -MinPlayersToStart=2 -log
```

再打开一个 PowerShell 窗口，启动客户端。客户端启动命令必须加上 `-windowed`，使用窗口化运行：

```powershell
Set-Location 'C:\UnrealProjects\BrokenEdge\Packaged'
& '.\Client\Windows\BrokenEdge.exe' /Game/Maps/Lobby -MatchType=Teams -windowed -log
```

客户端进入菜单后，点击加入房间。测试两名玩家时，在另一个 PowerShell 窗口执行同一条客户端命令，并让两个客户端都加入。

服务器大厅达到 2 名玩家后，会启动会话并切换到 `/Game/Maps/Teams`。进入比赛地图后仍有游戏模式自身的预热流程。专用服务器本身不占玩家名额。

## 3. 参数含义

| 参数 | 设置位置 | 含义 |
|---|---|---|
| `-MatchType=Teams` | 服务端、客户端 | 服务端创建团队模式房间；客户端搜索并加入同模式房间 |
| `-MatchType=FreeForAll` | 服务端、客户端 | 自由混战模式 |
| `-NumPublicConnections=8` | 服务端 | 房间最多容纳 8 名玩家，代码限制在 1～64 |
| `-MinPlayersToStart=2` | 服务端 | 至少 2 名玩家进入大厅后开始切图，代码限制在 1～房间容量 |
| `-windowed` | 客户端 | 使用窗口化运行；所有客户端启动命令都必须添加 |
| `-log` | 服务端、客户端 | 显示运行日志 |

当前大厅切图逻辑支持的模式字符串是 `Teams` 和 `FreeForAll`，请保持大小写一致。

人数参数不会自动创建客户端进程。客户端也不能通过这两个参数修改服务器人数限制。

例如，4 人团队测试可把服务端参数改为：

```text
-MatchType=Teams -NumPublicConnections=4 -MinPlayersToStart=4
```

如果希望单人先进入团队地图测试，可使用：

```text
-MatchType=Teams -NumPublicConnections=8 -MinPlayersToStart=1
```

## 4. 自由混战启动示例

服务器：

```powershell
& 'C:\UnrealProjects\BrokenEdge\Packaged\Server\WindowsServer\BrokenEdgeServer.exe' /Game/Maps/Lobby -MatchType=FreeForAll -NumPublicConnections=8 -MinPlayersToStart=2 -log
```

客户端：

```powershell
& 'C:\UnrealProjects\BrokenEdge\Packaged\Client\Windows\BrokenEdge.exe' /Game/Maps/Lobby -MatchType=FreeForAll -windowed -log
```

## 5. 默认配置与代码入口

项目的 [Config/DefaultGame.ini](../Config/DefaultGame.ini) 当前默认配置：

```ini
[MultiplayerSessions.DedicatedServer]
NumPublicConnections=8
MinPlayersToStart=2
MatchType=FreeForAll
bAutoStartSession=True
```

服务端先读取配置，再用命令行提供的模式和人数覆盖对应值。自动开局还要求配置中的 `bAutoStartSession=True`；当前代码没有为该开关读取同名命令行覆盖参数。修改源码目录里的配置不会自动更新已有打包产物，使用现有包时可通过上述命令行覆盖模式和人数。

相关实现：

- [MultiplayerSessionsSubsystem.cpp](../Plugins/MultiplayerSessions/Source/MultiplayerSessions/Private/MultiplayerSessionsSubsystem.cpp)：`InitializeDedicatedServer()` 读取服务端配置和启动参数。
- [LobbyGameMode.cpp](../Source/BrokenEdge/GameMode/LobbyGameMode.cpp)：`BeginPlay()` 读取客户端模式；`TryStartGame()` 检查开局人数并选择地图。
- [Menu.cpp](../Plugins/MultiplayerSessions/Source/MultiplayerSessions/Private/Menu.cpp)：`OnFindSessions()` 筛选模式一致且未满的专服房间。
- [TeamsGameMode.cpp](../Source/BrokenEdge/GameMode/TeamsGameMode.cpp)：处理团队分配、团队得分和友军伤害等团队规则。

## 6. 查看启动结果

服务端日志可重点查看：

```text
Dedicated bootstrap: Capacity=8 MinPlayers=2 MatchType=Teams AutoStart=1 LocalPlayers=0
Create complete: Success=1 Players=8 MatchType=Teams
Lobby: Players=1
Lobby: Players=2
Lobby travel: Map=/Game/Maps/Teams Players=2 Accepted=1
```

以上为预期日志示例，不是本次实测输出。其中 `Create complete` 的 `Players=8` 表示配置容量，实际已加入人数看 `Lobby: Players=...`。切图成功后，比赛开始时间还取决于游戏模式的预热设置。

若菜单没有找到房间，先检查服务器创建会话是否成功，以及客户端与服务器的 `MatchType` 是否一致。当前使用 `OnlineSubsystemNull`，跨机器测试还需处于可互通的局域网，并允许程序通过防火墙。
