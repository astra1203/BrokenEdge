# 输入动作清单

2026-11-13 原始资产审计：[InputActions.json](Artifacts/TechnicalDebt/WP11/InputActions.json)，基线 bbf1f4a82 + 只读审计脚本。共 10 个 InputAction、2 个 IMC。UE 5.8 的映射位于 DefaultKeyMappings；旧 Mappings 属性已经弃用且读出空数组，不能用来认证没有键位。

本期按方案先覆盖键鼠与重映射；手柄未支持完整操作。Widget 内 Esc/Enter/方向键仍属本地导航，不迁移。

## 当前实现

新增资产及来源见 [资产记录](Artifacts/TechnicalDebt/WP11Assets/来源.md)，绑定和真实重映射测试见 [迁移记录](Artifacts/TechnicalDebt/WP11Enhanced/实施记录.md)。下表保留迁移前清单用于对照。控制器 BindKey、旧 HoldBreath/InteractDoor 映射、G/Alt/R 原始键轮询已删除。IA_Heal 使用 Hold/Tap；低抛查询同一可重映射修饰动作，而非独立 Chorded 动作，以避免修饰键松开误投。背包 Tab/H 交给动作绑定，Esc/Enter/F/T 的局部 Widget 语义保留。

## 动作与取消语义

| 动作/默认键 | 上下文 | 当前入口 | 按下/持续/松开/取消 | 目标 IA |
| --- | --- | --- | --- | --- |
| 移动 WASD / 视角鼠标 | 地面 | Character Move/Look | Triggered 连续值 | IA_Move / IA_Look（现有） |
| 跳跃 Space / 冲刺 Shift | 地面 | Character Jump / Sprint | Started；松开/取消停止 | IA_Jump / IA_StingerSprint（现有） |
| 蹲伏 Ctrl | 地面 | Character Crouch | Started 切换 | IA_Crouch（现有） |
| 瞄准右键 / 开火左键 | 地面 | Character Aim/Fire | Started；Completed/Canceled 停止 | IA_Aim / IA_Fire（现有） |
| 换弹 R / 旧丢弃 G | 地面 | Character Reload/Drop | Started 单次 | IA_Reload / IA_Drop（现有） |
| 交互 E | 地面/救援 | Character Equip → PC Interact；PC 原始 E 松开 | 按下救援/交互；松开或取消停止救援 | IA_Equip（现有，计划统一为交互语义） |
| 屏息 LeftAlt | 地面开镜 | Character 旧 HoldBreath 映射 | 按下屏息；松开/取消停止 | IA_HoldBreath |
| 世界交互 F | 地面 | Character 旧 InteractDoor → PC | 滑索优先，其次电闸、普通门、钥匙门 | IA_InteractWorld |
| 菜单 Esc / 背包 Tab / 地图 M | 地面/菜单/背包/观战 | PC BindKey | 单次切换；进入交互 UI 时取消持续动作 | IA_Menu / IA_Inventory / IA_TacticalMap |
| 医疗 H | 地面 | PC UseMedical | 开始或取消医疗 | IA_UseMedical |
| 趴下 Z | 地面 | PC ToggleProne | 单次切换 | IA_Prone |
| 激素 V | 地面 | PC HealAbility/HealReleased，Tick 时间差 | 轻点切激素枪；持续 0.35 s 自用；取消不得视为轻点 | IA_Heal（Hold） |
| 烟雾 X / Alt+X | 地面 | PC SmokeAbility/Low | 按下高/低抛 | IA_Smoke / IA_SmokeLow（Chorded） |
| 手雷 G / Alt+G | 地面 | PC ThrowGrenade/Low，Tick 原始 G 轮询 | 按下预备；松开投掷；取消只收起 | IA_Grenade / IA_GrenadeLow（Chorded） |
| 标点鼠标中键 | 地面/倒地 | PC PlacePing | 单次标点 | IA_Ping |
| 武器 1 / 2 / 3 | 地面 | PC SelectPrimary/Secondary/Knife | 单次选择 | IA_SelectPrimary / IA_SelectSecondary / IA_SelectKnife |
| 旋转 R | 背包拖动 | LootingMainView UpdateDragRotation 原始轮询 | 按下一次旋转 | IA_RotateItem（UI IMC） |

取消入口应统一覆盖打开菜单/背包、切换 Pawn、倒地/死亡、窗口失焦。取消不能投雷或触发 V 轻点；Aim/Fire 缺少 Canceled 绑定需要补齐。尚未完成资产及绑定迁移，不把清单视为 WP-11 完成。
